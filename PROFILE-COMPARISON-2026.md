## Source corrections before publishing new downloads

1. **Bid amounts remain visible in Construction page 6.** Both values previously withheld from the website are back in this newly uploaded source. Prepare a redacted public copy, including tagged text, and keep “Available on request”. Reference names/telephone numbers are also printed there; the website summaries currently omit them. This source PDF is already tracked in Git following the pull; it is not currently served as a website download.
2. **Quotation addresses conflict with the latest instruction.** Construction page 7 and Mining page 10 still print `quotations@clementprojectssolution.co.za`. Public copies should use `sales@clementprojectssolution.co.za`, while enquiries remain `info@clementprojectssolution.co.za`. Lifting page 6 already lists info and sales correctly.
3. **The lifting inspection service names another business.** Lifting page 3 explicitly says “Inufa Lifting’s chain block inspection and repair service”. Clarify whether CPS performs this service or arranges it through that supplier before presenting it as CPS’s own service. Rewrite the PDF wording accordingly.
4. **Load charts are named, but numerical charts are absent.** Lifting page 5 lists working-load-limit charts and standards as product descriptions; it does not provide the corresponding numerical tables. Do not derive capacities or publish working-load tables from this file. The chain-sling list also uses “G10”; confirm the intended grade wording rather than guessing.
5. **Construction grade labels conflict internally.** Construction page 3 lists `1 CE`, `1 EP` and `1 GB`, while page 4 labels Electrical Construction `1 CE`. Resolve the source wording and check current records before adding grade-specific claims. The existing website avoids these claims.
6. **Website addresses are inconsistent.** The profiles mix `www.clementprojectsolution.com` with `www.clementprojects.co.za`. Use the approved website address consistently in revised public documents.
7. **Project status has not been refreshed.** A 2026 cover does not update the Dwellers record’s 2025 “still on process” wording. Keep its current status unconfirmed until the company supplies an update.
8. **Some document content needs editorial cleanup.** Examples include “Material Handeling”, “Electrical Infrustructure”, “Manual Chanblock” and “Wheal Hubs”. Construction photos also contain visible timestamps/location overlays. Review any selected imagery at full size and avoid representing equipment illustrations as completed CPS projects or proof of company-owned facilities.

The new Construction profile includes an NHBRC registration number not displayed on the website. Current supporting documents remain the appropriate basis for any expanded registration claims. The profile itself does not establish current certificate validity.
